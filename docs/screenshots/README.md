## Adding or replacing one

- Keep the 1080 px width and portrait crop so the grid stays even.
- Keep every image dark mode or every image light mode — a mixed row looks accidental.
- Use real seed data. Empty states make all the screens look alike.
- Write the alt text as a description of what the screen shows, not the filename. The README's images are the only place that information exists for a reader using a screen reader.

If a file is renamed, update the matching row in the root README's "Screens" table.
