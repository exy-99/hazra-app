## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#F0FDFA` light / `#0B1F1D` dark | App background |
| Secondary (30%) | `#FFFFFF` light / `#123330` dark | Cards, rows, sheets; hairline `border` `#CCE9E3` / `#205550`; track `muted` |
| Accent (10%) | `#EA580C` light / `#FB923C` dark | See reserved-for list ONLY |
| Destructive | `#DC2626` light / `#F87171` dark | Destructive actions + invalid-range inline hint only |

Accent reserved for: (1) Home full-width "Mark attendance" CTA; (2) Reports empty-state action button (single orange per screen state — same one-orange rule as 02-02/02-04). NOWHERE else: teal (`primary`/`secondary`) = structure/navigation/ring fill; `STATUS` solids/tints = status only, never reused for chrome; `destructive` text-only (never filled background) for remove confirmations, save-error text, and the custom-picker invalid-range hint.

Ring rule (design §7.1 + D-01): track `muted`, fill `secondary` (teal), turns `accent` below 75% (`ATTENDANCE_PCT_FLOOR`, component already implements). Row % text turns `accent` below 75 (D-18) — one floor app-wide. Zero countable days renders `—`, NEVER `0%`/`NaN` (D-12). Trend gap bars (zero-countable days) use `muted` + `—` label, never a 0% bar (D-22).

Dark mode: checked independently, never derived by eye. Contrast ≥ 4.5:1 both modes (status pills especially).

## Home Hero Layout (RP-01 · D-01..D-06)

Order top→bottom inside a `ScrollView` (16px gutters on children, `MaxContentWidth` 800 centered):

1. **Today's date** (`formatDisplay(todayKey())`, `body` or `label`, `mutedForeground`) above the ring (D-05).
2. **`AttendanceRing`** with `value = summarize(todayEntries).percentage`, rendered LARGER than profile's 120 (D-05; exact diameter at executor discretion, thumb-glanceable). Ring shows `—` until first mark of day (D-01). Today's rows come from `getAttendanceForDate(today)` — unmarked days ignored by `summarize()` (D-01).
3. **Counts row**: 4 STATUS read-only pills (tinted pill + dark text: Present/Absent/Half day/Off day + counts, `tabular-nums`, STATUS dots) from `getDailyCounts(date)` in the SAME scope as rows — never client math. Beneath: muted `"N unmarked"` line (`caption`, recedes, never competes — D-02).
4. **One orange CTA**: full-width "Mark attendance" → `/attendance`, always mounted (D-03).
5. **Pills tap through** to `/attendance` for triage (D-06) — hero is NOT read-only. Planner reconciles link target: deep-link to register at minimum; status pre-filter ONLY if cheap (attendance screen currently has worksite filter only, no status filter — do not silently invent a status-filter param).
6. **Zero-workers state**: calm §7.5-style `EmptyState` with "Add worker" → `/worker-form`; never a dead CTA (D-04).

Focal point: the ring numeral (`display` 48). Nothing else on Home competes — pills are small, the CTA is one flat bar.

## Reports Layout (RP-02..RP-05 · D-07..D-25)

Order top→bottom in a `ScrollView` (flat lists inside use `scrollEnabled={false}` + `keyExtractor` + memo rows — profile precedent):

1. **Worksite filter chips** (top): All + per-site, 02-04/03-05 pattern, `radio` role, `__all__` key (D-08).
2. **Range control** (below site chips): 7 / 30 / 90 preset chips (profile pattern) + custom From/To fields opening the DateStrip-style calendar modal; default Last 30 days on first open (D-07/D-11). Range end capped at today — future days never selectable (D-09). ONE scope: every stat and list follows the same (range, site) pair (D-08).
3. **Range aggregate**: `AttendanceRing` (`value = summarize(rangeEntries).percentage`) + 4 mini counts. Zero marks → ring `—` + calm §7.5 empty state, never `0%`/`NaN` (D-12).
4. **Bottom-3 callout** ("Frequently absent" wording at executor discretion): fixed bottom-3-by-% ABOVE the full list (D-14). Only workers WITH countable days rank; `—` workers excluded (D-19). Tie at 3rd/4th boundary: executor's discretion, must be deterministic (document choice in plan).
5. **Per-worker list**: sorted highest % first (D-13). Row = name + % (`tabular-nums`, `accent` text below 75 — D-18) + 4 mini counts with STATUS dots (D-17). `—` workers sink to bottom (D-19). Rows tap through to `/worker/[id]`; corrections stay in register (D-15). All per-worker % via `summarize()` over `getAttendanceForWorker(id, { from, to })` — exact register reconciliation (D-16).
6. **Trend chart** (RP-03 · D-20..D-23): one bar per day of the day's `summarize()` %, `react-native-svg`, labeled axes + legend (never color alone). Zero-countable days = `muted` gap bar + `—`. Ranges > 31 days bucket by week (weekly-boundary rule at planner discretion, deterministic). Active workers' marks in scope only (D-21). Read-only by default; bar→register tap-through only if trivial (discretion).

`getAttendanceForWorker` per-worker loop needs NO new DAO (canonical refs). Keep (range, site) scope + `summarize()` math importable (not screen-local) — Phase 6 Export consumes both.

## Interaction Contracts

| Contract | Rule |
|----------|------|
| Tap-throughs | Home pills → `/attendance` (D-06, target reconciled by planner). Report rows → `/worker/[id]` (D-15). No new routes in this phase |
| Filter retention | `selectedSite` sibling state next to range state; chip press sets site only, range press sets range only — retention is STRUCTURAL (03-05 precedent). Switching range/site keeps chips mounted + shows skeleton blocks over stats + list, never spinner swap or blank flash (D-10) |
| Custom picker gating (D-25) | Invalid ranges GATED, never auto-corrected: Save disabled until From ≤ To ≤ today + inline `destructive` hint. Sheet uses sibling absolute-fill `Pressable` scrim (03-01 precedent, `StyleSheet.absoluteFill` spread) |
| Loading | Skeleton blocks matching real row heights (profile `StatsSkeleton` precedent, lightweight pre-Phase-8); reserve space, nothing jumps |
| Failure | `load()` catch-all-inside + `void` callers + "Couldn't load …" / "Try again" (CR-01); focus refetch via `useFocusEffect(useCallback(...))` so register corrections reflect on back |
| Focus / refetch scope | Ring + counts + list (+ history-equivalent sections) share ONE period scope per screen, refetching together (04-02 precedent) |
| Pressables | `Pressable` ONLY (no `TouchableOpacity`); ripple + opacity 0.85; 44px targets, ≥8px gaps; `accessibilityLabel` on icon-only controls; status never color-alone (label text always) |
| Flat | No shadows/gradients/glassmorphism — 1px `border` + surface/background contrast only |

## Accessibility + Motion + Dark Mode

- **A11y:** every pill/chip labeled (STATUS label text, never color alone); ring keeps its `accessibilityLabel` (`Attendance N percent` / `No attendance`); chart has labeled axes + legend; icon-only controls get `accessibilityLabel` + `hitSlop`; focus rings visible (`ring` token).
- **Motion:** 150–300ms, ease-out enter / ease-in exit; opacity + transform only (ring sweep via `scaleX`/dash — the one delight moment); respect `AccessibilityInfo.isReduceMotionEnabled()` — skip sweep, keep state change. No decorative-only animation.
- **Dark mode:** every token pair above; check independently. Never hardcode hex — always import `useTheme()` / token (DS-03 gate).
