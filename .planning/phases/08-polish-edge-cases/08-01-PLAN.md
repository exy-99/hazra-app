| Reduced-motion hook | Event listener leak on unmount | root layout never unmounts, but the hook must still unsubscribe | Denial of Service (memory) | mitigate — `addEventListener` cleanup in `useEffect` return (T-08-01-a) |
| Starter deletion | Dead files (plan 08-08) break an unknown relative import chain | `./themed-text` siblings (`web-badge`, `hint-row` import each other; `collapsible` too) | Denial of Service | mitigate — deletion deferred to 08-08, which runs the app-wide Themed*-reference-zero gate AFTER this plan's decoupling, so tsc has no live importer to trip on |
| Splash hold | App visually frozen if fonts hang | `useFonts` resolves or errors — never hangs indefinitely; error path renders with system fallback per D-29 | Denial of Service | mitigate — the `fontsLoaded || fontError` join guarantees the gate opens |
