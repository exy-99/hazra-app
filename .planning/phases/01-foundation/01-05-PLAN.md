## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigate |
|-----------|----------|-----------|-------------|----------|
| T-05-01 | Tampering / SQL injection | all DAO queries | mitigate | Every value is a bound `?` parameter; no user string is concatenated into SQL. |
| T-05-02 | Tampering | accidental hard delete | mitigate | `deactivate*` performs `UPDATE ... SET is_active = 0`; a grep gate forbids `DELETE FROM` in this plan. |
| T-05-03 | Elevation of privilege | worker FK to a missing/deleted worksite | mitigate | `worksite_id` is `NOT NULL REFERENCES worksites(id)`; the migration/DAO never deletes worksites. |
| T-05-04 | Information disclosure | inactive rows in new-entry pickers | mitigate | Active-list queries filter `is_active = 1` by default; `includeInactive` is explicit opt-in. |
</threat_model>
