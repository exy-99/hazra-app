<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| route param `id` → later DAO calls | A string from the URL crosses toward SQL (used in Phase 4) |
| init failure → app runtime | A DB error must not crash the app silently |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigate |
|-----------|----------|-----------|-------------|----------|
| T-08-01 | Tampering / SQL injection | `worker/[id]` param | mitigate | Route reads `id` as a string only; it must be passed parameterized to DAOs, never concatenated. |
| T-08-02 | Denial of service | double DB init under React 19 double-invoke | mitigate | Module-level `initialized` guard + idempotent `initDatabase` (`IF NOT EXISTS`). |
| T-08-03 | Information disclosure | accidental network in layout/components | mitigate | Phase-wide grep gate asserts no `fetch(`/`axios`/`XMLHttpRequest` in the Phase 1 product files; offline by design (NF-01). |
| T-08-04 | Denial of service | unhandled init rejection → blank/crash | mitigate | try/catch sets `dbError`; a readable error screen replaces the tabs; splash always hidden in `finally`. |
| T-08-05 | Tampering | token drift (DS-03) | mitigate | Phase-wide grep gate asserts no `#RRGGBB` literal in the Phase 1 product files; all color comes from `src/constants/theme.ts`. |
</threat_model>
