<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| URL param → form | `?id=` untrusted; DAO-resolved before use |
| form → SQLite | Name/role/phone/worksite_id cross into SQL as bound params |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-13 | Tampering | `?id=` param (`/worker-form?id=nope`) | mitigate | `getWorker(id)` resolution; `null` renders "Worker not found" EmptyState; raw param never interpolated into SQL |
| T-02-14 | Injection | name/role/phone strings, worksite_id | mitigate | All values travel as `?`-bound params via `createWorker`/`updateWorker`; `worksite_id` comes from DAO-loaded site objects, never typed input |
| T-02-15 | Tampering | assigning to a soft-deleted worksite | mitigate | Selector lists `listWorksites()` active-only; in edit mode, a legacy inactive `worksite_id` still pre-selects by id (history intact) but saving requires picking an active site |
</threat_model>
