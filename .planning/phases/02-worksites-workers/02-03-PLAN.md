<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| URL param → form | `?id=` is untrusted; must resolve via DAO before use |
| form → SQLite | All user strings cross into SQL; must travel as bound parameters |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-07 | Tampering | `?id=` param (`/worksite-form?id=nope`) | mitigate | Resolve with `getWorksite(id)`; on `null`, render "Worksite not found" EmptyState — never interpolate the raw param into SQL or UI queries |
| T-02-08 | Injection | name/address/type strings | mitigate | Pass user strings only as `?`-bound params through `createWorksite`/`updateWorksite` (parameterized DAO from Phase 1); type comes from the fixed `WORKSITE_TYPES` tuple, never free text |
| T-02-09 | Denial of service | oversized input | accept | Single-user offline app; SQLite TEXT is unbounded by design; no server to exhaust |
</threat_model>
