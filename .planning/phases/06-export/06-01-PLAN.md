## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| note/worker-name → CSV cell | Untrusted user text crosses into spreadsheet-parseable file (formula injection risk) |
| worker/site name → filename | Untrusted user text crosses into filesystem path (traversal risk) |
| note/name → PDF HTML | Untrusted user text crosses into HTML renderer (XSS risk) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-01 | Injection (formula) | escapeCsvField in src/utils/export.ts | mitigate | Prefix fields longer than 1 char starting with `= + - @` with `'`; probe-covered in verify script |
| T-06-02 | Traversal | slugify/workerFilename/registerFilename + writeTextFile basename strip | mitigate | Allowlist `[a-z0-9]+` joined by `-`, `|| 'unknown'`; `filename.split('/').pop()` at write; yyyymm(dd) derived from validated local keys only |
| T-06-03 | XSS | buildWorkerPdfHtml/buildRegisterPdfHtml | mitigate | escapeHtml() applied to every interpolated value; no raw note/name/date in HTML |
| T-06-04 | Info disclosure | shareFile in src/utils/files.ts | accept | Shares only the generated file uri; dismiss changes nothing; rationale: share is the explicit EX-03 user action |
