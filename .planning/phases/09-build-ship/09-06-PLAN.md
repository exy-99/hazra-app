## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| human operator → Expo credential/build service | Privileged account, key, quota, and build actions cannot be delegated to the agent. |
| Expo build record → downloaded APK | Exact build-ID selection and binary inspection establish artifact provenance. |
| credential vault / APK archive / Git | Secrets, distributable bytes, and source must remain in separate custody zones. |

## STRIDE Threat Register

| Threat ID | Category | Threat | Disposition | Concrete mitigation and verification | Owner | Residual risk |
|-----------|----------|--------|-------------|--------------------------------------|-------|---------------|
| T-09-P06-01 | Information Disclosure / DoS | Keystore/password is exposed or signing recovery is lost. | mitigate | User-only remote credential workflow, encrypted off-repo recovery copy, recovery-access check, empty sensitive tracked-file scan, no secrets in summary, credential vault separate from handoff. | human | Vault/provider/account loss remains possible; recorded custodian/recovery reference enables operational recovery. |
| T-09-P06-02 | Spoofing | Wrong EAS owner/project/credential is used. | mitigate | H1 owner/UUID, H2 credential history and certificate fingerprint, H3 project/build record, and H4 signer fingerprint must all agree; stop on mismatch. | human | Authenticated service compromise remains outside local control. |
| T-09-P06-03 | Tampering / DoS | Package/signing/version drift blocks updates and threatens SQLite data. | mitigate | AAPT2 verifies package/version/versionCode; apksigner verifies signature/fingerprint; remote auto-increment; no local versionCode; same key recovery; no-uninstall rule in handoff. | human with agent-authored contract | First install does not itself prove a later update; continuity inputs are captured for the next release. |
| T-09-P06-04 | Spoofing / Tampering | Debug/preview/AAB is substituted for production release APK. | mitigate | Exact `production`/Android build record, `.apk` extension, build-ID download, AAPT2, apksigner, independent launch in 09-07; reject wrong artifact class. | human | Build-service metadata must be read accurately; raw outputs are retained. |
